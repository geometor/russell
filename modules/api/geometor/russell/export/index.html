geometor.russell.export¶

Exporters for GEOMETOR Russell 3D Cosmogony scenes (.obj, .json, .svg).

Allows exact mathematical sharing between: - Blender / MeshLab / CAD pipelines (Wavefront .obj) - Interactive WebGL / Canvas studios (.json) - Print & Book Codex vector plates (depth-sorted 3D camera .svg)
